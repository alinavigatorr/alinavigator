# ADR 002: Centralized Motion & Animation System

**Status:** Accepted
**Date:** [Current Date]
**Sprint:** 4

## Context
انیمیشن‌های پراکنده و کنترل‌نشده می‌توانند تجربه کاربری را ارزان جلوه دهند و باعث افت پرفورمنس یا ایجاد مشکل برای کاربران حساس به حرکت (Motion Sickness) شوند.

## Decision
کتابخانه `framer-motion` به عنوان موتور اصلی انیمیشن انتخاب شد با رعایت قوانین زیر:
- **Easing مرکزی:** استفاده از منحنی حرکتی پرچمدار `cubic-bezier(0.32, 0.72, 0, 1)` برای تمام ترانزیشن‌ها.
- **Accessibility:** استفاده اجباری از هوک `useReducedMotion` در تمام کامپوننت‌های متحرک برای احترام به تنظیمات سیستم عامل کاربر.
- **Micro-interactions:** محدود کردن انیمیشن‌های Hover به تغییر مقیاس جزئی (Scale: 1.02) و Tap (Scale: 0.98).

## Consequences
**Positive:**
- حس تعامل (Feel) بسیار روان و حرفه‌ای مشابه اپلیکیشن‌های Native.
- رعایت کامل استانداردهای دسترسی‌پذیری (A11y).
**Negative:**
- افزایش جزئی حجم باندل جاوا اسکریپت در سمت کلاینت.
